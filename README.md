# Universal Downloader

Download videos and photos from **YouTube, Facebook, Instagram, Threads, X, Pinterest, TikTok and LinkedIn** on Mac and Windows.

## Download

Get the latest version from **[Releases](../../releases/latest)**:

| Platform | File |
|---|---|
| Mac (macOS 14+, Apple Silicon & Intel) | `Universal-Downloader-<version>.dmg` |
| Windows 10/11 (64-bit) | `Universal-Downloader-<version>.exe` |

Installed apps update themselves: when a new version is released here, the app shows **Update now**.

## First launch

- **Mac:** drag the app to Applications. The first time, macOS blocks it because it isn't from the App Store:
  open System Settings → Privacy & Security and click **Open Anyway**. Setup then runs automatically (about 30 seconds).
- **Windows:** if "Windows protected your PC" appears, click **More info → Run anyway**, then **Install engines**.

Only download content you have the right to use.
